# DICTA 2026 Workshop Website

GitHub Pages-ready static website for **Vision-Language and Agentic AI Modeling in Image-guided Theranostics**.

## Deploy
1. Create a GitHub repository, e.g. `dicta-2026-workshop`.
2. Upload all files from this package to the repository root.
3. Commit to `main`.
4. Open **Settings → Pages**.
5. Choose **Deploy from a branch**.
6. Select **main** and **/(root)**.
7. Save.

## Files
- `index.html` — one-page workshop website
- `assets/styles.css` — responsive design
- `assets/script.js` — mobile menu
- `.nojekyll` — GitHub Pages compatibility
